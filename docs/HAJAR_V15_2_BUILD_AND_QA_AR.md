# HAJAR Portfolio V15.2 | تقرير التطوير وفحص البناء

**الحالة:** تحسينات تم اختبارها محلياً. **لا يوجد بناء Next.js إنتاجي ناجح بعد**، ولا يوجد مجلد `out/` ناتج من Next.js.

## التعديلات المنفذة

1. إضافة `scripts/preview-export.mjs` لخدمة مجلد التصدير الثابت `out/` محلياً على `127.0.0.1`. يدعم مسارات Next.js ذات الشرطة المائلة الختامية وملفات الصور والخطوط وCSS وJavaScript، ويقيّد الطلبات إلى GET/HEAD ويمنع التنقل خارج المسار والروابط الرمزية. ليس خادماً عاماً للإنتاج.
2. إصلاح `npm start` ليتوافق مع `output: "export"`، وإضافة `npm run preview:export` مع خيارات `--dir` و`--port`.
3. فصل ناتج CI للمراجعة عن الإنتاج: ملفات مراجعة للـ Pull Request أو الفرع المستقل أو التشغيل اليدوي، وملفات النشر فقط عند `push` إلى `main` بعد نجاح الفحوص. تقييد محتويات حزمة Netlify إلى `out/` و`netlify.toml`.
4. تحديث فحص Chromium الخاص بـGitHub Actions ليستخدم خادم المعاينة الجديد.
5. منع حدث CI اليدوي من تشغيل فحص الموقع المنشور تلقائياً على أنه نشر جديد.
6. إضافة أربعة اختبارات جديدة لخادم المعاينة ومسارات CI وحمايتها، وتحديث README.

## نتائج التحقق المنفذ فعلياً

- اختبارات Node: **92/92 ناجحة** (قبل التعديل 88/88).
- `tests/v15-build-preview.test.mjs`: اختبر صفحات متداخلة وملفات CSS وHEAD و404 و405 والمسارات المشفّرة الخطرة والروابط الرمزية، بالإضافة إلى شروط CI.
- ملفات GitHub Actions: التحليل التركيبي YAML ناجح.
- فحص Chromium بالتحميل المستقل للمحتوى: المعاينة البصرية وملف `public/resume.html` على 320 و390 و768 و1440 بكسل بلا تمرير أفقي أو استثناءات JavaScript.
- فتح Chromium لعنوان `http://127.0.0.1` محظور بسياسة البيئة (`ERR_BLOCKED_BY_ADMINISTRATOR`): لم يكتمل اختبار خادم HTTP *داخل المتصفح*. خادم HTTP اختُبر مباشرةً باستجابات Node/HTTP.
- `npm ci --offline`: فشل برمز ENOTCACHED لحزمة `zod-validation-error@4.0.2`.
- `npm run build`: فشل برمز 127 لأن أمر `next` غير مثبت. لا تعتبر هذه نتيجة لفشل كود التطبيق، لكن لا يمكن إثبات نجاحه من دون الاعتماديات.
- لم أرفع أو أنشر أي شيء على GitHub أو Render أو Netlify.

## طريقة الحصول على البناء الفعلي

على جهاز أو GitHub Actions مزوّد باتصال إلى npm، من جذر `portfolio-main`:

```bash
npm ci
npm run check:release
npm run preview:export -- --port 4173 --dir out
```

ثم افتح `http://127.0.0.1:4173/` واختبر صفحات المشاريع والتنقل والبحث وAI Atlas. يمكن تشغيل `Portfolio CI` يدوياً على فرع مراجعة للحصول على artifact باسم `hajar-nextjs-preview-...`. **لا تستخدم push إلى `main` فقط بغرض المراجعة** لأن هذا الفرع قد يفعّل النشر المكوَّن في المستودع.

هذا التقرير لا يعدّ اعتماداً إنتاجياً، ولا يُغني عن اختبارات التطبيق المبني داخل المتصفح.
