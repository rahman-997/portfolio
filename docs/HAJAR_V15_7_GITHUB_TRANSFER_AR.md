# HAJAR V15.7 | نقل الشيفرة إلى فرع المراجعة

## الحالة المؤكدة

- مستودع GitHub: `rahman-997/portfolio` (عام).
- فرع المراجعة موجود: `review/hajar-v15-5-qa-20261102`.
- في وقت الفحص كان SHA الفرع مساوياً لـ SHA `main`: `7512a4c317b0ea25bee32c3c41a52b333d12ceea`.
- لم تُرفع الشيفرة المصدرية من هذه الحزمة إلى الفرع بعد، ولم يُنتج `out/` لهذه النسخة.
- بيئة التنفيذ الحالية لا تستطيع حل نطاق `github.com` أو `registry.npmjs.org`، ولذلك لا يمكن تنفيذ `git push` أو `npm ci` منها.

## أبسط طريقة على Windows

1. فك ضغط `HAJAR_Personal_Portfolio_V15_7_Review.zip` في مجلد عادي.
2. تأكد من وجود Git وNode.js 22 على الكمبيوتر، واتصال GitHub.
3. افتح مجلد `portfolio-main/scripts` وشغّل `hajar-review-windows.cmd` أولاً: **فحص فقط، دون كتابة أو نشر**.
4. بعد نجاح الفحص، افتح Terminal داخل مجلد `portfolio-main` وشغّل:

```powershell
.\scripts\hajar-review-windows.cmd --push
```

الأداة تنشئ فرع مراجعة محلياً، تنسخ ملفات المصدر المسموحة فقط، ثم تدفع الفرع إلى GitHub دون لمس `main`. ترفض العملية إذا تغيّر رأس الفرع البعيد عن نقطة الأساس التي جرى فحصها.

## خطوات التحقق على GitHub

1. افتح: `https://github.com/rahman-997/portfolio/tree/review/hajar-v15-5-qa-20261102`.
2. تأكد أن SHA الجديد مختلف عن `main` وأن الملفات الجديدة موجودة.
3. افتح `Actions` ثم `Portfolio CI` على تنفيذ `push` الخاص بفرع المراجعة.
4. تحقق من نجاح `npm ci`، `lint`، `typecheck`، `next build`، واختبارات التصدير والمتصفح. **لا تعتبر تشغيل اختبارات Node المحلية إثباتاً للبناء**.
5. حمّل ملف المراجعة `out/` من Artifacts إذا أنتجه CI، واختبر محتواه قبل أي نشر.

- لا ترفع ملف `Portfolio1_HAJAR_Integrated_V11_Review.zip` إلى المستودع، لأنه يحتوي على مواد إنستغرام الداخلية. استخدم حزمة الموقع المنفصلة فقط.
