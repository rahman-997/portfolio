# بناء HAJAR الإنتاجي (Next.js)

هذا المشروع يستخدم `output: "export"`، لذلك **ناتج النشر هو المجلد `out/`** بعد اجتياز البناء والتحقق. لا تنشر مجلد المصدر بدلاً منه.

## الطريقة الأولى: GitHub Actions (مفضلة عند تعذّر الاتصال من الجهاز المحلي)

1. ارفع نسخة المصدر المحدثة إلى مستودعك **بعد مراجعة التغييرات**. رفع الملفات أو تشغيل Actions لم يحدث آلياً.
2. افتح المستودع ثم **Actions → Portfolio CI → Run workflow** على الفرع `main`.
3. تنتظر بوابة CI نجاح `npm ci`، واختبارات الواجهة، وESLint، وTypeScript، و`next build --webpack`، وفحص الملفات المصدّرة.
4. إذا نجحت جميعها، نزّل الملف **`hajar-nextjs-production-<commit>`** من قسم **Artifacts** داخل تشغيل CI.
5. محتوى الحزمة هو الموقع الثابت الجاهز لاستضافة Static Hosting. اختبره محلياً عبر خادم HTTP، ولا تفتحه مباشرة عبر `file://`.

إذا فشل أي فحص، لن تُنشأ حزمة بناء موثقة. هذا سلوك مقصود.

## الطريقة الثانية: البناء على جهازك

المتطلبات: Node من `.node-version`، وnpm من `packageManager` في `package.json`، واتصال يعمل بسجل npm.

```bash
npm ci --no-audit --no-fund
npm run check:release
```

بعد النجاح فقط:

```bash
npx http-server out -p 4173
```

افحص `/` و`/resume/` ودراسات الحالة الأربع، والقائمة والبحث وAI Atlas على الكمبيوتر والموبايل.
