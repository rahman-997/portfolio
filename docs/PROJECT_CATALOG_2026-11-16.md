## Boundaries and provenance

Names and descriptions were checked against repository documentation and existing project handoff/source packages. Private repository URLs, personal assets, customer information and credentials are excluded from the gallery. Culture-SY describes the contact/link page contribution only. VenueFlow Pro is distinct from Venues API; ATHRUA is distinct from HAJAR Studio. AI Marketing Agents describes the automation backend.

Stage badges distinguish public demos, development projects, prototypes and the attributed open-source fork. A public demo badge means that a demo link is provided, not a production certification. This catalog change does not certify the operation of every underlying product.

## Verification

Static export checks require all 22 unique IDs on all three language routes and restrict GitHub links to the existing 7 public repositories. Browser checks cover name search, Turkish dotted/dotless-I matching, Arabic concept search in every UI language, combined category/search filtering, empty-state reset and absence of private source links. Existing theme, RTL, no-JavaScript and mobile checks are retained.

A scoped minimatch override addresses GHSA-g3hv-75wg-m249 in the TypeScript ESLint toolchain. No production deployment or main-branch merge is included.
